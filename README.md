# Personality Quiz  

## Описание проекта  
**Personality Quiz** – интерактивный веб‑тест, который за 30 вопросов определяет тип личности, предпочтительный стиль работы, карьерные рекомендации и скрытые таланты. Приложение реализовано как прогрессивное веб‑приложение (PWA) и может работать офлайн благодаря Service Worker.

## Основные возможности  

| № | Возможность | Краткое описание |
|---|--------------|------------------|
| 1 | **Тест из 30 вопросов** | Вопросы разбиты по категориям (социальные навыки, мышление, досуг и т.д.). |
| 2 | **Анализ ответов** | На основе весов ответов рассчитываются 18 психологических черт. |
| 3 | **Определение MBTI‑типа** | Выводится код типа (например, ENFP) и его название. |
| 4 | **Социальный тип** | Выделяется «Экстраверт», «Интроверт» или «Амбиверт». |
| 5 | **Рекомендации по карьере** | Список подходящих профессий, стилей работы и способов обучения. |
| 6 | **История результатов** | Последние 20 тестов сохраняются в `localStorage`. |
| 7 | **Оффлайн‑режим** | Service Worker кэширует все ресурсы, позволяя проходить тест без интернета. |
| 8 | **PWA‑манифест** | Возможность установить приложение на мобильное устройство как нативное. |
| 9 | **Адаптивный дизайн** | UI подстраивается под любые экраны, поддерживает «safe‑area» на iOS. |
|10| **Темная тема** | Цветовая палитра оптимизирована для темных экранов. |

### Краткое описание ключевых файлов  

| Файл | Содержание |
|------|------------|
| **index.html** | Разметка всех экранов (welcome, quiz, results, history). Подключает стили, шрифты, манифест и скрипты. |
| **manifest.json** | Описание PWA: название, цвета, иконки, режим отображения `standalone`. |
| **sw.js** | Кеширует `index.html`, CSS, JS, манифест и иконки; обслуживает запросы из кеша, обновляя их при необходимости. |
| **css/style.css** | CSS‑reset, переменные темы, стили компонентов, анимации переходов. |
| **js/app.js** | Главный контроллер: инициализация `Quiz`, `ResultsRenderer`, привязка событий, регистрация Service Worker, проверка истории. |
| **js/quiz.js** | Управление текущим вопросом, рендеринг UI, навигация «назад», «пропустить», сохранение прогресса. |
| **js/questions.js** | Массив объектов `QUESTIONS` (id, category, text, варианты ответов). |
| **js/data.js** | Объект `DATA` с весами черт (`answerTraits`) и названиями MBTI‑типов (`typeNames`). |
| **js/analyzer.js** | Функции `calculateTraits`, `getPersonalityType`, `getSocialType` – преобразуют ответы в баллы и типы. |
| **js/results.js** | Формирует вывод: код типа, название, графики, списки сильных/слабых сторон, рекомендации. |
| **js/storage.js** | Обёртка над `localStorage`: сохранение/загрузка ответов, текущего индекса, результатов и истории. |

## Установка и запуск локально  

1. **Клонировать репозиторий**  
   ```bash
   git clone https://github.com/your-username/personality-quiz.git
   cd personality-quiz
   ```

2. **Установить простой HTTP‑сервер** (Node.js)  
   ```bash
   npm install -g serve   # один раз
   serve -s .             # запустит статический сервер на http://localhost:5000
   ```

   *Можно использовать любой другой сервер (Python `python -m http.server`, VS Code Live Server и т.п.).*

3. **Открыть в браузере**  
   Перейдите по адресу, указанному в консоли (обычно `http://localhost:5000`). Тест будет работать в офлайн‑режиме после первого загрузки.

## Как добавить/изменить вопросы  

1. Откройте `js/questions.js`.  
2. Добавьте новый объект в массив `QUESTIONS`:

   ```js
   {
       id: 31,
       category: "Creativity",
       text: "Как вы относитесь к творческим задачам?",
       answers: [
           { id: "a", text: "Люблю придумывать новые идеи" },
           { id: "b", text: "Предпочитаю проверенные решения" },
           { id: "c", text: "Иногда пробую, но не часто" },
           { id: "d", text: "Не интересуюсь творчеством" }
       ]
   }
   ```

3. Добавьте соответствующие веса в `js/data.js` под ключом `"31_a"`, `"31_b"` и т.д.:

   ```js
   "31_a": { creative: 5, artistic: 3 },
   "31_b": { practical: 4, analytical: 2 },
   // …
   ```

4. При необходимости обновите `typeNames` или добавьте новые типы в `DATA`.

## Сборка и деплой  

Проект — чистый статический сайт, поэтому сборка не требуется. Для публикации на GitHub Pages:

```bash
git checkout -b gh-pages
git push origin gh-pages
```

GitHub автоматически обслужит содержимое ветки `gh-pages`. Убедитесь, что в настройках репозитория включён **GitHub Pages** из этой ветки.

## Тестирование PWA  

| Действие | Ожидаемый результат |
|----------|---------------------|
| Открыть сайт в Chrome → `Ctrl+Shift+I` → вкладка **Application** → **Manifest** | Появятся название, иконки, цвета, `display: standalone`. |
| На той же вкладке выбрать **Service Workers** | Статус **Running**, кеш `pq-cache-v1` содержит все файлы. |
| Отключить интернет и перезагрузить страницу | Тест загружается из кеша, полностью работает офлайн. |
